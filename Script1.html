01

语文课 · 预防教育

日 · 内教室喜剧 + 预防

开场三分钟，先用两个喜剧点把观众拉进来——同学甲打瞌睡被粉笔砸醒喊"到"，同学乙追被风吹散的试卷滑倒。然后进入正题：龙老师讲《百合花》。这节课讲的每一句话，都会在后面被剧情回应。课间还有第三个笑点：同学丙传纸条被念"中午食堂吃啥"。最后，A 在窗口偷看 B——恨意的种子从这里埋下。

粉笔头正中同学甲的脑门。同学甲惊醒，猛地站起来。
同学甲
"到！"
全班哄堂大笑。
龙老师
"坐。梦里讲到哪了？"
同学甲
"报告老师……梦里您刚说要默写。"
龙老师
"《百合花》里，通讯员和新媳妇从头到尾没说过一句喜欢，可那床百合花被子，比任何表白都重。真正的好感，是尊重对方、不打扰对方、盼着对方好——不是急着说出口，是把它放得干干净净，变成自己向上的劲。记住了吗？"
讲这段时语速放慢，每句之间停半秒。

课间表白 · 反面示范

A 顺着 B 的视线看过去。C 正抱着作业本站在办公室门口。A 的笑容僵住，眼神从不服气变成恨意。

03

放学走廊 · 正确示范

日 · 外走廊夕阳侧光

全片最暖的一场戏。B 和 C 并肩走出教室，边走边对答案。题目讲完，安静两秒，B 鼓起勇气开口——却被 C 用语文课上的《百合花》温柔接住。不说教，不冷脸，用对方能接受的方式，说一件正确的事。这段戏用下午四五点的夕阳侧光，色调温和，是整部片子的"正确答案"。

B
"那个……其实……"
脚步慢下来，手插兜又拿出来，低头看鞋。
C
"你是不是想说，你喜欢我？"
停下脚步，歪头笑一下。不是调侃，是"我都知道，没关系"。
C
"龙老师今天刚讲的《百合花》，你听懂了吗？"
B
"听懂了。"
C
"那我们就先各自站好。先把这次月考考好了，行不行？以后有的是时间。"
把书包往肩上一甩，动作利落。
B
"……行。"
抬头，释然一笑。

04

厕所霸凌 · 反面案例

日 · 内女厕所冷色 · 手持

C 独自走进女厕所。角落里，A 带着两个小跟班在等她。锁门、堵门、抓衣领、揪头发、泼水、扇巴掌——整个段落没有一句台词，全靠动作和卡点。所有动作全部借位完成：抓衣领只抓布料，踢腿只拍轨迹，扇巴掌离脸 5 厘米，泼水泼向镜头。拍得安全，但成片的效果是完整的冲击力。

C
"你们要干嘛？！"
洗手时听到门响，转头。声音发抖，但强装镇定。
A
"上。"
一个字。抬下巴示意小跟班，声音低沉，不喊。
小跟班1 反手锁门，"咔嗒"一声。小跟班2 叉腰堵在门口。A 缓缓走近 C，不说话，抬下巴。
抓衣领、推搡、抬脚、揪头发、泼水、扇巴掌——全程借位，镜头只拍施暴方。鼓点骤停在最后一个巴掌。

告师 · 处分 · 黑屏

日 · 内/外多场景落点

B 路过厕所，从门缝里看见了一切。他没有冲进去硬拼——转身狂奔去找龙老师。这就是课堂上讲的"第一时间告诉老师"。龙老师赶到，制止霸凌，把三人带去办公室。班长在班会上宣布开除。本以为故事到此为止——处分后的 A 走在走廊，被人无意撞到，慢慢抬头，眼神再次凶狠。

B
"报告！龙老师，一楼女厕打起来了，C 被打了！"
撑住办公室门框，弯腰喘气，断断续续。
龙老师
"什么？！走！"
从椅子上弹起，椅子刮地，抓教案就往外走。
龙老师
"你们三个，跟我来办公室。"
先蹲下看 C，再缓缓抬头看三人。一个字一个字说清。
A
"……至此，我深刻认识到自己的错误，向 C 同学道歉。对不起。"
照稿念，"对不起"几乎听不见。念到一半卡壳，掏小抄。
班长
"由于 A、小跟班1、小跟班2 三位同学屡教不改……学校给予开除处理。大家引以为戒。"
A
"你要干嘛？！"
被撞后慢慢抬头，眼神变狠，攥拳。说完直接黑屏。

黑场字幕

高中时代的心动，很正常。

但那不是爱情，是你第一次学着理解一个人。真正的喜欢，是把成绩一起往上拉，不是把彼此往下拽。

看见有人被围在角落，去找老师，让这件事被看见，就是最勇敢的选择。

被围住的人请记住：错的是动手的人，不是你。

10 / 12
创作构思

我们为什么这样写

Approach
01 / 伏笔

用课堂做全片的预防针

《百合花》不是随便选的课文——它讲的就是"不说出口的喜欢"。课堂讲的每一句，后面都在剧情里被回应。

02 / 对照

把"正确"和"错误"都拍出来

C 用课堂上学到的道理婉拒 B——正确处理的示范。A 表白被拒后迁怒——错误处理的示范。对比鲜明。

03 / 落点

B 不硬拼，去告诉老师

很多校园片拍到霸凌现场就停了，但"看到之后该怎么做"才是最有价值的部分。B 的行为直接回应课堂台词。

04 / 悬念

黑屏前的最后一句

A 被处分后还凶狠——说明种子没消失。黑屏留白，让观众自己往下想，比说教更有力量。

05 / 安全

霸凌戏全程借位

抓衣领只抓布料、踢腿只拍轨迹、扇巴掌离脸 5cm、泼水泼向镜头。既拍出冲击力，也保护演员。

06 / 闭环

五幕是一个整体

预防 → 埋雷 → 示范 → 爆发 → 落点。每一幕都有明确功能，没有一秒钟是浪费的。
